# Publication publique

Ce dépôt présente uniquement les fonctions de l’application publique. Les README, guides, changelog, validations, titres et descriptions de releases doivent rester dans ce périmètre. Ne pas y publier les fonctionnalités, essais ou instructions propres à un autre dépôt. Vérifier ce périmètre avant chaque publication GitHub et conserver les nettoyages éditoriaux de l’utilisateur.

# Graphify

Quand `graphify-out/graph.json` existe, utiliser Graphify avant les recherches larges : `graphify query`, `graphify path` ou `graphify explain` selon la question. Après une modification structurelle, exécuter `graphify update .`. Si aucun graphe n’existe, continuer normalement.
